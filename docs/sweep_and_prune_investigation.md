# Sweep and Prune と本手法 (Certified Pruning) の比較調査

## 1. Sweep and Prune (SAP) の概要

Sweep and Prune (SAP / Sort and Sweep) は、主に物理エンジンやコンピュータグラフィックスにおける**衝突判定（Collision Detection）の広域判定（Broad-Phase）アルゴリズム**の代表例です。

*   **仕組み**: 各オブジェクトを Axis-Aligned Bounding Box (AABB) と呼ばれる軸に平行な境界ボックスで囲み、x, y, z 軸それぞれに射影（Sweep）して 1D 区間の重なりを判定します。全ての軸で同時に重なりを持つペアのみを抽出し（Prune）、コストの高い詳細判定（Narrow-Phase）へと渡します。
*   **利点**: 動的シミュレーションにおいて「前のフレームから物体は少ししか動いていない」という時間的コヒーレンスを利用し、挿入ソートを用いることでほぼ $O(N)$ でリストを更新できるため、非常に高速です。

## 2. 本手法（Anisotropic Čech Filtration の Certified Pruning）との差異

本リポジトリの `docs/certified_pruning_sync.md` に記載されている枝刈り戦略（Theorem B, C, D, E 等）と SAP には、目的とアプローチに根本的な差異があります。

| 比較項目 | Sweep and Prune (SAP) | 本手法 (Certified Pruning) |
| :--- | :--- | :--- |
| **対象・目的** | 物理エンジンのペア衝突判定 (2体間の交差有無) | 位相的データ解析 (TDA) の Čech 複体構築 (k-単体の交差と filtration value) |
| **パラメータ** | 時間 $t$ (動的なオブジェクトの移動) | スケール $r$ (静的な点群の半径の成長) |
| **幾何学的近似** | AABB (Axis-Aligned Bounding Box) | KKT条件に基づく Rayleigh商の下限球 (Theorem Bの距離グラフ $G_L$) |
| **出力されるもの** | 衝突「候補」のペア (グラフの枝) | トポロジーを保証された単体集合とその厳密な発生値 $\alpha$ |

## 3. 適用ギャップ (なぜ直接の適用が難しいか)

ご指摘の通り「トポロジーを保つような reduction の方が嬉しい」という点が最大のネックであり、SAP の単純な適用を困難にしています。

1. **高次単体 (Clique) の組合せ評価への拡張性**
   SAP は基本的に「2体間（グラフのエッジ）」の判定に特化しています。一方で Čech 複体の構築では 3点、4点... の共通部分（高次単体）を評価する必要があります。SAP でエッジを絞れたとしても、そこから単体を列挙するフェーズには直接寄与しません。本手法（Theorem G）は、グラフの最大次数 $\Delta$ を用いてこの組合せ爆発を理論的に抑え込むアプローチをとっています。

2. **非等方性 (Anisotropy) と AABB の相性の悪さ**
   本手法が扱う「非等方楕円体」を x,y,z 軸に沿った AABB で囲むと、楕円体が斜めに細長い場合、実体積に対して AABB の体積が極端に大きくなります。結果として、無駄な「重なり」が大量に検出されてしまいます。本手法では行列の最小固有値（Rayleigh bound $m$）を直接使った距離グラフ $G_L$ を構築しており（Theorem B）、こちらの方が非等方性に対して強靭かつ厳密な bound を与えます。

3. **トポロジー保存 (The Act Map / Del^aniso) の証明との両立**
   本手法の目的は単なる計算のサボりではなく、「ホモトピー同値性を保ったまま filtration を縮約する (Theorem E, Act Map)」ことです。SAP のような空間的ヒューリスティクスを外側から被せると、「どの単体がどの段階で棄却されたか」の厳密な管理が難しくなり、Lean で証明中のモース理論に基づく persistence の同一性（Theorem I 等）が壊れる、あるいは証明が非常に困難になるリスクがあります。

## 4. 関連先行研究 (State of the Art) の配置

TDA 界隈における計算量削減アルゴリズムの SoT と、本手法の位置づけは以下のようになります。

1. **空間分割・AABBベースのアプローチ (TDA版のSAP的アプローチ)**
   *   等方的な Vietoris-Rips 複体や Čech 複体を計算する際、GUDHI などのライブラリでは Kd-tree などの空間分割アルゴリズムを利用して近傍探索（ペアの発見）を高速化しています。これは TDA における SAP に近い立ち位置ですが、あくまで「等方的な球」を前提としています。
2. **Edge-Contraction / 離散モース理論ベースのアプローチ (SoT)**
   *   本手法の `act map` や `Del^aniso` に直結するアプローチです。ホモトピー同値を保ちながら単体複体を小さくする研究（例: Edge collapse for Vietoris-Rips complexes）が近年活発です。
3. **本手法の特異性**
   *   上記のようなモース理論的な縮約を、「非等方 (Anisotropic) Čech 複体」の「KKT 条件 (Minimax value)」に直接結びつけ、さらに Lean で形式的証明 (Formal Verification) を与えながらアルゴリズム化しようとしている点が、本手法の独自の SoT（State of the Art）と言えます。

## 5. 結論

SAP の x, y, z 射影による枝刈りは直感的で強力ですが、(1) 非等方な境界の緩さ、(2) トポロジー保存（Act map / 値の再利用）の厳密なトラッキングとの相性の悪さから、本プロジェクトの目的とはギャップがあります。

現状の `certified_pruning_sync.md` に記載されている計画（Theorem B による近傍グラフ構築と、Theorem E による区間値の再利用）は、まさに「トポロジーを保つような reduction」を KKT 最適化の数学的裏付けのもとで実現するものであり、計算の高速化と証明の完全性を両立するための最適なアプローチであると結論づけられます。
